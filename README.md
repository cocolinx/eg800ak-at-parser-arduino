# CocoLinx EG800AK AT command parser Library for Arduino

## Description

A C++ based AT command parser library for CocoLinx EG800AK.

## Features

- Network attach / detach control
- UDP / TCP / MQTT

## Installation

1. Download ZIP file
2. Open Arduino IDE and go to **Sketch -> Include Library -> Add .ZIP Library**
3. Add .ZIP file
4. Click **Sketch -> Include Library -> CocoLinx EG800AK AT Parser Library**

## Examples

 - FullTest_Example: An all-in-one integration example that exercises most library features, including UDP, TCP and MQTT for quick sanity and setup verification.
 - MQTT_Example: Connects to LTE, connects to an MQTT broker, subscribes to a topic, and publishes a message.
 - UDP_Example: Connect to LTE, open a UDP socket, and sends/receives data with an echo server.
